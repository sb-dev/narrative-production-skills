# Artifact Contract — Narrative Develop

This skill may create or refine `narrative_brief`, `story_concept`, `character_profile`, `world_bible`, `story_outline`, `beat_sheet`, and `scene_card`.

`narrative_brief` preserves originating intent and hard constraints. `story_concept` answers what story is being told. `character_profile` stores story-relevant motivation, relationships, arc, knowledge and behavioural constraints. `world_bible` stores story-relevant rules and setting constraints. `story_outline` is a complete lower-resolution story model. `beat_sheet` stores meaningful changes with cause/effect. `scene_card` stores a scene's dramatic function before high-resolution writing.

Workflow state (`draft|refine|final`) is separate from decision status (`candidate|selected|approved|rejected|superseded`). Approved decisions become downstream constraints until explicitly reopened.
