# Pack Authoring Artifacts

`narrative-pack-create` works with four authoring artifacts:

- **pack definition** — the installable `SKILL.md` contract and activation behaviour;
- **production profile** — medium, genre, style, audience, optional voices, constraints, defaults, evaluation and handoffs;
- **showcase example** — a realistic example README containing the exact generation prompt;
- **pack evals** — behavioural cases proving activation, application, precedence, refinement and boundaries.

These are authoring artifacts. They do not add new first-class story artifacts to Narrative Production Skills.
