# Progressive Examples

These examples grow from one controlled story output to long-form continuity and cross-domain handoff. They are not a canonical consumer directory tree; each example adds structure only when its production responsibilities require it.

1. `01-short-story` — complete small narrative loop.
2. `02-mystery-continuity` — beliefs, secrets, canon and multi-scene state.
3. `03-screenplay` — scene cards, Fountain and developmental revision.
4. `04-episodic-story` — multiple episodes and evolving arcs.
5. `05-film-handoff` — narrative artifacts handed to downstream production domains.
