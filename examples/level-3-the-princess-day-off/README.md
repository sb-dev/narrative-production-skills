# The Princess's Day Off

**Level 3 — Develop and execute a screenplay**

**Genre:** fantasy adventure comedy

A royal bodyguard discovers the princess has slipped into a festival in disguise just as a ceremonial procession makes returning unseen almost impossible.

## Prompt

```text
Use Narrative Production Skills to develop and write an 8-page fantasy-adventure screenplay sequence titled “The Princess's Day Off”.

Premise:
Royal bodyguard Taren finds Princess Sol in a crowded midsummer market, disguised as an apprentice baker after slipping away from a ceremonial appearance. Taren's objective is to return her to the palace unnoticed. Sol's objective is to experience one ordinary hour. Then the royal procession unexpectedly changes route and enters the market.

Requirements:
- Medium: screenplay
- Genre: fantasy adventure comedy
- Tone: energetic, playful, character-led
- Use both dialogue and physical action
- Establish only the world information the scene needs
- Sol must have a concrete reason for leaving beyond generic rebellion
- Taren must face a genuine choice between duty and protecting Sol's agency
- The procession should escalate existing objectives rather than introduce an unrelated threat
- Do not specify shot design, camera movement, lighting or visual character design
- Output Fountain-compatible screenplay pages

Workflow:
- Develop character objectives and the minimal festival/world constraints
- Build a scene card and beat progression before pages
- Plan action so every physical beat changes the dramatic situation
- Draft the screenplay
- Evaluate action readability, dialogue, character turn, pacing and medium fit
- Revise only the affected beats if the action becomes confusing or the character decision is unearned

What to optimise for:
- readable action
- comic escalation
- character-specific conflict
- fantasy economy
- a clear scene turn
- downstream freedom for visual production
```

## What this example demonstrates

Translate medium-independent story decisions into scene cards and Fountain-compatible screenplay pages across comedy, romance and action while keeping audiovisual direction downstream.

```text
story intent → scene cards → screenplay → developmental evaluation → bounded screenplay revision
```

This example is one of three productions at Level 3. The level is the capability target; the different stories test whether that capability transfers across genres, tones and audience expectations.
